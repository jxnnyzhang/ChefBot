What's powering ChefBot's recipe search.

  • Edamam Recipe Search API ↗ Live recipe results are pulled from Edamam's recipe database via a Cloudflare Worker proxy, matched against the ingredients you list.
  • delicious.com.au ↗ Source of the Poke Bowl trending recipe.
  • taste.com.au ↗ Source of the Carne Asada trending recipe.
  • Local fallback dataset If Edamam is ever unreachable, ChefBot falls back to a small hand-curated recipe list so it still works offline.
